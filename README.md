# 369journal.app

Marketing site for **369 Journal** (369 Manifestation: Journal), the 369 method journal for iPhone.
Plain static HTML and CSS, hosted on GitHub Pages at https://369journal.app.

- `index.html`: home
- `369-method/`: how-to guide, plus `tracker/` (printable 33-day tracker)
- `best-369-method-apps/`: comparison
- `faq/`: FAQ (with FAQPage structured data)
- `robots.txt`, `sitemap.xml`, `llms.txt`: search and AI crawler files

Preview locally: `python3 -m http.server 8369`, then open http://127.0.0.1:8369.
